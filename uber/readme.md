# 🚖 Uber Rides Analysis  

## 📌 Overview  
Exploratory Data Analysis (EDA) and Tableau dashboards on Uber ride data to uncover booking trends, cancellations, ride metrics, and ratings.  

## 🔍 Steps  
- **EDA (Python)** → Cleaned & analyzed bookings, distance, fare, and ratings  
- **Tableau Dashboards** →  
  - **KPI Dashboard**: Bookings 📊, Distance 📏, Fare 💵, Ratings ⭐👨‍✈️  
  - **Ride Insights**: Time-based trends, cancellations, payment modes, locations  

## 📈 Tech Stack  
- Python (Pandas, Matplotlib, Seaborn)  
- Tableau  

## 🎯 Outcomes  
- Insights on cancellation patterns  
- Ride distance vs fare relationships  
- Customer vs driver ratings & payment preferences
